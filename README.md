# CISCOM for Windows

Installers for the CISCOM desktop app (Windows 10 and 11, 64-bit).

**To download and install, go to https://ciscom.co/download** — it has the steps, including what to click when Windows shows a warning.

- Latest installer: https://ciscom.co/download/latest
- Each release lists its files and a `SHA256SUMS.txt` with their SHA-256 checksums.

The installers are not yet code-signed (Microsoft's verification is in progress), so Windows SmartScreen shows "Windows protected your PC" the first time. Click **More info**, then **Run anyway**.
